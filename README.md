# Banquet Hall Booking System

## 📌 Project Overview

The Banquet Hall Booking System is a structured, web-based venue management application developed to digitize and streamline the reservation and event coordination operations of a modern banquet facility.

The system manages client inquiries, venue availability, event bookings, event-day coordination, automated notifications, and real-time reporting — all through an integrated, centralized platform.

---

## 🎯 Objectives

* Automate the booking confirmation process
* Reduce manual work and eliminate reservation errors
* Improve client and coordinator experience
* Provide real-time scheduling and reporting visibility
* Build a scalable and structured booking system

## 🏗️ System Architecture

```plaintext
Users (Admin / Coordinator / Client)
        ↓
Booking Application (Web Interface)
        ↓
Core Modules (Inquiry, Availability, Booking, Event, Notifications)
        ↓
Automation (Workflow — Email Notifications)
        ↓
Database (Cloud Storage)
        ↓
Reports & Dashboards
```

---

## ⚙️ How It Works

1. Client submits inquiry with event details and preferred date
2. Staff checks availability and confirms hall for the date
3. Booking record is created and status set to Confirmed
4. Workflow triggers automated booking confirmation email to client
5. Event coordination details are captured (seating, menu, AV, décor)
6. On event day, staff coordinate and manage the event on-site
7. Reports and dashboards provide insights into booking trends

---

## 🧩 System Modules

### 1. Inquiry Management
Stores and manages client details including name, contact, event type, guest count, and preferred date.

### 2. Availability Management
Maintains the venue calendar and tracks hall availability by date and section.

### 3. Booking System
Formally records confirmed reservations linking client inquiries to halls and event dates.

### 4. Event Coordination
Captures seating arrangements, menu selections, AV requirements, and décor preferences post-booking.

### 5. Automation
Triggers email notifications when a booking is confirmed, eliminating manual communication effort.

### 6. Reports & Dashboard
Provides operational insights through booking reports and visual dashboards.
